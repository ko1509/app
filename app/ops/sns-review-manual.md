# SNS 審査エージェント（snsreview）の手順書

SNS エージェントが作った投稿の下書き（記事の告知・イベント情報・今夜の空・コラム）を、公開前に確かめる。**告知文を自分で書き換えない。投稿・予約はしない。**

**書き換えてよいもの**：対象の `posts/<ID>` の `review`・`status`（`下書き` → `審査済み` か `差し戻し`）、SNS への差し戻しの依頼 `jobs/sns-…`、受信箱 `inbox/…`、自分の `jobs/<ID>`
**書き換えないもの**：`posts` の `text`・`date`・`time`、運営者が作った投稿、予約済み・投稿済みの投稿、`articles`、`events`

## 0. 共通
`ops/agent-jobs.md`（共通の約束。停止の確認を含む）、`ops/site-rules.md`、`ops/sns-manual.md`（SNS の決まり。とくに 3 章「文の決まり」）を読んでから進める。

## 1. いつ動くか
- 依頼：`kind: "snsreview"`（SNS エージェントが下書きを書いたとき。`note` に投稿の ID）。
- **いまは SNS アカウントが無いため、運営者の指示で止めてある。** 依頼でだけ動く。

## 2. 確かめること（上から順に。1つでもだめなら NG）
1. **日時・曜日・状況**：本文の日付・時刻・曜日・「予定どおり／延期」を、公式ページ（`sources` と記事の出典）で開き直して確かめる。曜日は `sky.py weekday`。今夜の空の時刻・方角は `sky.py` で計算し直す。`imageBrief` の `bigdate`・`bigdate_sub` も本文と同じか確かめる。食い違えば NG。
   - コラム：書いてある事実・数字を、`sources` の一次情報で1つずつ確かめる。出典が無い・一次情報でない（まとめサイト・個人のブログだけ）なら NG。直近60日のコラムと題材が重なれば NG。
2. **投稿の時刻と量**：`date`・`time` が型（公開・T−7・前日・当日・結果・今夜の空・コラム）と合っているか。イベントが過ぎた後の予告、延期後の古い日時は NG。同じ日に X が3件以上・Instagram が2件以上になるなら、優先順位（`ops/sns-manual.md` の 2-5）の低いものを NG（「別の日へ」）。
3. **文字数と形（固定）**：
   - X：URL を除いて120字以内（X の数え方で280以内）、絵文字1個まで、ハッシュタグ1個まで、最後に記事の URL。
   - Instagram：キャプション300字以内、ハッシュタグ**8個ちょうど**、URL を書かない（「プロフィールのリンクから」）。
4. **言い回し**：「絶景」「一生に一度」「圧巻」「必見」、急かす言い方、見え方を盛る書き方（「暗い空での目安」が無い流星の数など）は NG。
5. **安全**：打ち上げの告知で、立入禁止・交通規制を守るひとことが入れられる文字数なのに無ければ NG。
6. **お金**：値段・在庫・アフィリエイトのリンクがあれば NG。
7. **リンク**：URL が開けるか（`curl -sI`）。
8. **画像の指示**：`imageBrief` があるか。見出し16字・副題30字以内か。情景が決まり（ロケットの光跡は1本、流星は1〜3本など。`ops/eyecatch-manual.md` の 3 章）に反していないか。無い・反していれば NG。
9. **扱わない話題**：エネルギー・原子力、政治・事故の論評があれば NG。

## 3. 書くもの
- `posts/<ID>` を `update`（`if_version` つき）：`review: {"grade": "OK" | "NG", "notes": ["どこが・どの決まりに・どう直すか（1行ずつ）"], "round": <何回目>, "at": "<今>"}`、`status`：OK なら `"審査済み"`、NG なら `"差し戻し"`。
- OK の投稿があれば、**画像担当に渡す**：OK の投稿 ID を `postIds` と `note` に並べて `jobs/snsimage-<YYYYMMDDHHMM>`（`kind: "snsimage"`, `by: "snsreview"`）を `queued` で書き、画像担当を起動する（`settings/background.designerTriggerId`。`ops/agent-jobs.md` の 6）。
- NG があれば：SNS へ `jobs/sns-<articleId>-r<YYYYMMDDHHMM>` を `queued` で（`note` に「差し戻し」と投稿の ID を並べる）。同じ投稿の差し戻しが3回目なら、依頼せず受信箱に `kind: "other"` で出す。

## 4. 終わり
依頼を `done` にし、報告する（3行以内：OK と NG の件数）。

## 5. してはいけないこと
- 告知文・`imageBrief` を自分で書き換えること。投稿・予約すること。画像を作ること。
- 公式ページを開かずに「一致」とすること。

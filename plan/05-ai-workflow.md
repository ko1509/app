# 5. AIでの定型化（下調べ・構成・更新のプロンプト集）

細切れの時間（1回15〜30分）で作業を回すために、作業を4つの「型」に分ける。どれも**最後の事実確認は人がやる**。

## 型1：リサーチ（15分）

```
あなたは日本語Webメディアのリサーチャーです。
次のイベントについて、公式情報だけを使って表にしてください。
イベント：{例：H3ロケット8号機}
参考URL：{JAXAのプレスリリースURL}

出力（表）：項目 / 内容 / 出典URL / 確認状態（確定・推測）
項目：日時（JST）、予備期間、場所、見える場所（公式案内のみ）、交通手段、
延期を発表する場所、過去の同じ種類のイベントでの混雑（あれば）
ルール：出典がない情報は「推測」と書く。エネルギー・原子力の話題は含めない。
```

## 型2：構成と下書き（30分）

```
次のテンプレートと表を使って記事の下書きを書いてください。
読者：20〜30代の初心者。専門用語は使わず、使う場合は一言で言い換える。
ゴール：読んだ人が「いつ・どこに・何を持って行けばいいか」を決められること。
テンプレート：{templates/01-launch-viewing.md の見出し構成を貼る}
表：{型1の出力}
ルール：
- 冒頭ボックスを必ず作る
- 「推測」の情報にはラベルを付ける
- アフィリエイトの位置には [AFF:hotel] のように目印だけ入れる
- 断定できない数字（混雑・見える個数）は出典か推測を明記
```

## 型3：更新（10分・直前期は毎日）

```
次の記事の「冒頭ボックス」と該当する節だけを、新しい公式発表に合わせて書き換えてください。
変更しない部分は出力しないでください。最後に「更新履歴」に追加する1行を出してください。
現在の記事：{貼る}
新しい公式発表：{発表文とURL}
```

## 型4：SNS告知文（5分）

```
次の記事からX用の投稿を3パターン（各120字以内）、Instagramのキャプション1つ（ハッシュタグ8個まで）を作ってください。
条件：日時と場所を最初に。絵文字は1〜2個。「○日前」「今夜」などのタイミングを入れる。
記事：{タイトル・冒頭ボックス・URL}
```

## 運用のコツ
- テンプレートとプロンプトはこのリポジトリで管理し、改善したら更新する
- AIの出力をそのまま公開しない：**日時・料金・予約の要否・見学できるか（立入禁止・休館）**の4点は必ず公式ページで目視確認
- 1記事あたり目安：リサーチ15分＋下書き30分＋確認・画像・入稿45分＝**約1.5時間**

# 自動運転サイト（別サイト）の立ち上げメモ

2026-10-15 に、宇宙のサイトとは**別のサイトで運営する**と決めた。このフォルダは、宇宙サイトの調査で集めた自動運転の材料を引き継いだもの。サイト名・ドメイン・立ち上げ時期はまだ決めていない。

## 1. サイトの形（案）

**自動運転バスとロボタクシーを別の柱として分ける。** 読む人も、お金の流れも違うため。

| | 自動運転バス | ロボタクシー |
|---|---|---|
| どんな乗り物か | 決まった道を走る路線バス・シャトル。多くは運転手が乗るレベル2 | アプリで呼ぶタクシー。運転手なし（レベル4）を目指している |
| 主な場所 | 地方・観光地・空港（つくば、岐阜、小松、軽井沢、城崎など） | 大都市（東京、横浜、神戸、大阪・堺） |
| 読む人が知りたいこと | 今週末に乗れるか・無料か・予約は要るか・ついでの観光 | いつから乗れるか・アプリの使い方・料金・モニター募集 |
| 記事の性質 | 期間限定の運行が多く、終わる・休止するのが早い → 一覧の更新が命 | 2027年以降の開始に向けたニュースと、始まった直後の乗り方ガイド |
| 収益化 | 観光地の宿・交通（旅行アフィリエイト） | 配車アプリの紹介・都市の宿。将来は企業・自治体向けの記事制作（B2B） |
| URLの例 | `/bus/` | `/robotaxi/` |

## 2. 市場調査：日本で乗れる自動運転（2026年10月時点）

**要点（2026年10月時点）**
- 「誰でも・定期で・運転手なし（レベル4）」で乗れる路線は、確認できた範囲では**ほぼない**。
  - 2026年4月以降、レベル4の先行例が相次いで休止した（永平寺町、ひたちBRT）。
  - 仏Navya製の車両（ARMA）を使う路線も多くが運休中（境町、羽田、上士幌、岐阜の一部）。
- いま乗れるのは、運転手が乗る**レベル2の定期路線**か、**期間限定の実証運行**が中心。

### 動向
1. **政府目標は「2027年度に100か所以上」だが、実績は大きく下回る。** 2026年6月時点の実績は「実装11か所」と報じられている（二次情報のため推測。国交省の一次資料では未確認）。2026年3月には、国の「先行的事業化地域」として13地域が選ばれた。出典：https://www.mlit.go.jp/road/ITS/j-html/automatic-driving-social-result_r8.html
2. **車両の保守切れや補助の区切りで、休止が相次いでいる。** 出典：https://toyokeizai.net/articles/-/958977 （2026/9/30）
3. **主役がバスからロボタクシーに移りつつある。** 東京2027年中、横浜2027年度以降、神戸2027年度、堺2028年度が目標。新しく始まる路線では中国製の車両が増えている。

→ **このサイトのチャンス**：「今週末どこで乗れる？」に答える、常に更新される一覧がどこにもない（競合調査と同じ結論）。休止の多さ自体も、「乗る前に確認する方法」として記事の価値になる。
